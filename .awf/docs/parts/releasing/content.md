A release is one compatible public Git snapshot for the Pi bridge, its product skill, and Python distributions. Pin Pi and Python separately to the same full commit SHA; tags are readable release identifiers, not immutable evidence until resolved and locked.

Before tagging, run `./awf render`, `./scripts/check`, and `./scripts/check-release`. The release lane creates a temporary clean commit from the selected working snapshot and drives Pi's real Git-package startup plus both Python dependency forms without publication. After pushing a tag, run `./scripts/check-release --public-ref <tag> --expected-sha <full-40-character-sha>` to fetch that public ref, require it to resolve to the intended immutable commit, and repeat the adopter checks. `py-science-formula` and `pi-science` are AGPL-3.0-only; do not publish to npm or PyPI.
