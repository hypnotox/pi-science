# Plan: Implement exact weighted optimization objectives

## Goal

Let ordinary advice and direct optimization select a bounded exact-symbolic objective, return replayable plans with canonical objective provenance and qualified ordering, and preserve current behavior by default. Do not change ordinary unit-work reports, candidate comparison, dominance, candidate semantics, search families, or the deferred cost and runtime models.

## Architecture summary

Keep the retained five-dimensional operation tally and opaque primitive work in Python. Add one optimizer-only objective projection: absent selection is `unit_work_v1`; `weighted_operations_v1` uses five strictly positive values parsed through the existing bounded exact-scalar grammar and keeps opaque work at coefficient one. Feed that projection through the existing common complete-candidate verifier and sorter while leaving `WorkAnalysis.total_work` and every non-optimization consumer unchanged.

Both ordinary optimization configuration and direct optimize requests select the same Python-owned policy. Plans replace ambiguous work evidence with selected-objective before, after, and savings evidence, carry canonical objective provenance separately from unchanged candidate identity, and distinguish proved savings superiority from deterministic non-superiority ordering. Replay candidates remain ordinary analysis inputs without objective controls. Pi protocol v14 strictly correlates, transports, and presents these fields without evaluating weights, work, or ordering. The public Python, schema, adapter, TypeScript, presentation, active documentation, and current-state migration lands as one atomic green transaction.

- `dod: protocol-v14-transport` Python, generated schema, adapter, TypeScript validation, and Pi presentation agree on protocol v14; strict tests reject legacy or malformed shapes and demonstrate that Pi validates correlation without recomputing mathematical policy.
- `dod: current-documentation` The four ADR state changes are applied, active generated and hand-authored guidance describes the shipped exact-objective boundary consistently, semantic rendering review is recorded, and historical records remain unchanged.
